# PROBEXR Frontend

React 19 + Vite frontend with premium auth UX, real-time streaming, and modern design.

## Highlights

- Social Login (Google, GitHub) and Magic Links
- Real-time SSE streaming with automatic fallback and connection robustness
- SWR for smart data fetching, caching, and conditional revalidation
- Service Worker integration for offline support and caching assets
- Code-split lazy loading with minimal skeleton loading screens
- React Error Boundary for app-wide crash protection
- Dark mode with smooth UI transitions
- 108 frontend tests — 100% pass rate, ready for E2E testing
